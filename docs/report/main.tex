\section{Introduction}

This document describes the development of the
\textit{Granular RVEs} research software project, a
three-dimensional computational mechanics framework for studying
realistic granular microstructures using FEniCSx.

The project is being developed as a research-oriented software
framework for finite element modelling of granular assemblies,
with an emphasis on reproducibility, verification, validation,
and extensibility toward homogenization, uncertainty quantification,
and data-driven surrogate modelling.

The initial computational program progresses from single-grain
mechanics to interacting grains, periodic assemblies, and realistic
three-dimensional granular microstructures. Later stages will address
homogenization, parameter identification, uncertainty quantification,
and data-driven surrogate models.
